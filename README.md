# datarheo.io
datarheo.io Lighting platform to move data

## Running the website

This is a basic Node.js website built with [Express](https://expressjs.com/).

### Prerequisites
- Node.js (v18+ recommended)
- npm

### Setup
```bash
npm install
```

### Start the server
```bash
npm start
```

The website will be available at [http://localhost:3000](http://localhost:3000).
